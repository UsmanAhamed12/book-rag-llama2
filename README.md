# Book RAG Llama2

A production-ready Retrieval-Augmented Generation (RAG) application built with:

- FastAPI
- React
- ChromaDB
- Ollama (Llama2)
- Sentence Transformers
- Docker
- GitHub Actions
- AWS

## Features

- PDF ingestion
- Semantic search
- Local LLM inference
- Source-aware answers
- REST API
- Modern React UI
- Dockerized deployment
