# 📚 Book RAG with Llama 3.2

A production-ready Retrieval-Augmented Generation (RAG) application that answers questions from PDF books using a local LLM.

---

## 🚀 Tech Stack

### Backend
- FastAPI
- Python 3.12
- uv
- Loguru
- Pydantic Settings

### AI
- Ollama
- Llama 3.2
- ChromaDB
- BAAI/bge-small-en-v1.5

### Frontend
- React + Vite (planned)

### DevOps
- Docker
- GitHub Actions
- AWS
